Harmonies

Jeu de société en C++ — exécuté en mode console dans votre navigateur

Harmonies a été développé en C++ avec une double interface : une version graphique Qt et une version Terminal (CLI) (le binaire harmonies_console du projet). Cette page exécute la version console dans un terminal simulé par xterm.js : il s'agit d'un port JavaScript fidèle du code C++ (mêmes règles, mêmes menus, même affichage), jouable immédiatement dans le navigateur.

Le code source C++ d'origine se trouve dans LO21projet/ : main_console.cpp, ConsoleInputHandler.cpp, ConsoleRenderer.cpp, SetupMenu.cpp et le moteur (core/, rules/, scoring/). Le port JavaScript reprend exactement la même logique : coordonnées hexagonales even-q offset, règles d'empilement des jetons, motifs des cartes animales, esprits de la nature et calcul de score.

harmonies.exe — Console ▣
Déroulement d'une partie (identique au C++) :
1. Configuration : nombre de joueurs (1-4), côté du plateau (A/B), option « Esprit de la nature » (y/n), noms des joueurs.
2. Chaque tour : choisir une action dans le menu numéroté (prendre un slot du marché, prendre une carte animale, choisir son esprit, poser un cube animal/esprit…).
3. Poser les jetons obligatoires sur le plateau hexagonal (coordonnées q r) puis terminer son tour.
Légende : W=Eau  S=Pierre  E=Terre  T=Arbre  F=Champ  B=Bâtiment  (minuscule = cube posé)

Compiler la version C++ en WebAssembly (optionnel)

Le port JavaScript ci-dessus suffit pour jouer. Pour exécuter le vrai code C++ compilé en WebAssembly, compilez la version console (qui n'utilise pas Qt) avec Emscripten :

# Depuis LO21projet (liste des sources identique au .pro console) emcc src/main_console.cpp \ $(find src/core src/model src/rules src/scoring src/ui src/utils -name '*.cpp' ! -path '*/qt/*' ! -name 'VuePartie.cpp') \ -I include \ -std=c++17 -O3 \ -s WASM=1 \ -s MODULARIZE=1 \ -s EXPORT_NAME=createHarmoniesModule \ -s ALLOW_MEMORY_GROWTH=1 \ -s NO_EXIT_RUNTIME=1 \ -o game/harmonies.js

Cette piste WASM n'est pas encore câblée dans le port actuel : le terminal exécute pour l'instant le port JavaScript fidèle, qui reproduit déjà les mêmes règles et le même déroulement que le binaire harmonies_console.

Le projet

  • Programmation de la logique d'état complexe (manches, tours, placement, scoring) et gestion des timers.
  • Développement d'une interface graphique interactive avec le framework Qt, en plus de la version console.
  • Architecture découpée en services testés (TurnManager, PlacementValidator, ScoreCalculator…).
