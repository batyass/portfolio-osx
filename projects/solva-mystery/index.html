Solva Mystery

Jeu d'enquête 3D propulsé par l'IA

Solva Mystery est un jeu vidéo d'enquête 3D immersif dans lequel l'intelligence artificielle génère dynamiquement les dialogues et les comportements des personnages non-joueurs. Développé sous Unity 6000, le jeu s'appuie sur un système de navigation (NavMesh) pour un gameplay « Point & Click » multi-scènes, et des dialogues verrouillés par un prompt engineering strict.

Technologies

Unity 6000 API OpenAI (GPT-4o) Sora DaVinci Resolve WebGL

Jouer dans le navigateur

Le jeu est compilé en WebGL depuis Unity. Le build (dossier build/ généré par Unity) est chargé ci-dessous dans une fenêtre plein-jeu, sans bordure, adaptée à la largeur de l'écran.

⚠️ Le chat avec les PNJ nécessite une clé API. L'exploration, les déplacements et la scène fonctionnent sans configuration. En revanche, poser des questions aux suspects fait appel à l'API OpenAI (api.openai.com) et échoue si aucune clé n'est intégrée au build. La clé se configure côté projet Unity (dans le code C# qui appelle l'API, ou via le script de configuration du jeu), puis se recompile dans le build WebGL — elle ne se saisit pas depuis le navigateur.

Réalisations

  • Implémentation d'un système de navigation (NavMesh) pour un gameplay immersif « Point & Click » et une gestion multi-scènes.
  • Génération de dialogues dynamiques via un prompt engineering strict pour verrouiller les profils psychologiques des PNJ.
  • Création d'un trailer promotionnel avec l'IA vidéo Sora et montage de continuité visuelle sur DaVinci Resolve.
